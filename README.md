# Nizy

Nizy is an experimental artificial intelligence systems project focused on building a persistent, autonomous and extensible AI runtime.

## Goals

- Persistent long-term memory
- Local AI inference
- Autonomous task execution
- Browser and web automation
- Tool and API integration
- File and media processing
- Continuous self-evaluation and improvement
- 24/7 Linux runtime

## Current Status

Nizy is under active development and testing.

The project is currently being developed on Linux and requires stable compute infrastructure for benchmarking, experimentation and long-running services.

## Infrastructure

The project benefits from:

- 4+ vCPU
- 6+ GB RAM
- SSD/NVMe storage
- Public IPv4/IPv6
- Root access
- 24/7 availability

## Project Direction

The long-term goal is to develop Nizy into a general-purpose persistent AI system capable of maintaining memory, interacting with tools, executing tasks and operating continuously across different interfaces.
